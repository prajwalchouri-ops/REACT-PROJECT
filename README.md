# IPL Ticket Booking

A React and Vite app for browsing IPL fixtures, booking tickets, and viewing booking history.

## Run locally

```bash
npm install
npm run dev
```

Bookings work locally with browser storage. To connect Supabase, add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to a `.env` file.
